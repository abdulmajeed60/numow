# لوحة متابعة طلاب نمو — نسخة العرض

نسخة للعرض فقط من لوحة متابعة طلاب فريق نمو. بيانات الطلاب في `data.enc.json` مشفّرة (AES-256-GCM بمفتاح مشتق من كلمة المرور عبر PBKDF2) ولا تُقرأ دون كلمة المرور.

- `index.html`: صفحة اللوحة وشاشة الدخول.
- `data.enc.json`: البيانات المشفّرة، تُحدَّث تلقائيًا بعد كل مزامنة مع منصة خليل.
- `tools/encrypt.mjs`: أداة التشفير التي تستخدمها مهمة المزامنة.

لا تضع كلمة المرور أو بيانات غير مشفّرة في هذا المستودع.
